# Iteration plans

Files in this directory are **historical planning snapshots** for a single development iteration. They are **not** maintained docs.

- Do not update a plan to match later implementation unless explicitly asked.
- When a plan conflicts with code or READMEs, **code and READMEs win**.
- For current API, setup, and usage, use [README.md](../../README.md), [docs/architecture.md](../architecture.md), and the live API at `/docs`.
